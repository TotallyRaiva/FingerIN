WHY IT FEELS LIKE HARDWARE

REAL-TIME AUDIO & RHYTHM ENGINEERING

Built from the ground up in Swift to eliminate the sluggishness of typical educational games—every pad strike fires directly on the CoreMIDI real-time thread before the UI even renders the next frame.

ZERO-LATENCY RT AUDIO PATH

Direct CoreMIDI Thread Sample Triggering

Standard macOS apps hop onto @MainActor before playing audio, adding 8–16ms of UI frame jitter. FingerIN caches the active MIDI-to-Voice lookup table behind an OSAllocatedUnfairLock and triggers pre-started AVAudioPlayerNode voices directly inside the high-priority CoreMIDI callback thread—paired with selectable sample transient trim modes (RAW 0ms, TIGHT 2ms, ULTRA 5ms).

MIDIManager.readProc (CoreMIDI RT Thread) ──► DataManager.voiceForNoteRealtime(_:) ──► AudioManager.triggerSoundRealtime(_:velocity:)
120HZ DETERMINISTIC ENGINE

Phase-Locked SpriteKit Scheduler

Replaces drift-prone timer loops with a single frame-accurate update(_:) clock that drives falling note positions, scrolling bar/beat grid lines, phase-aligned metronome clicks, and signed millisecond feedback (EARLY -11ms / LATE +8ms).

MUSICAL FEEL

Velocity Layers & Hi-Hat Choke

Every drum voice is pre-rendered across 3 dynamic timbre tiers (Ghost, Normal, Accent) with pitch/saturation sculpting and an authentic MPC hi-hat choke group where Closed Hat immediately cuts Open Hat ring-out.

ACCOMPANIMENT SYNTH

Built-In Rhodes & Bassline

Practicing bare drums in isolation feels sterile. FingerIN synthesizes style-matched electric piano chords and sub-bass grooves using a 4096-entry lookup table oscillator (fastSinUnit) pre-warmed at level load.

HARDWARE CALIBRATION

MIDI Learn, Hot-Plug & Offset

Auto-detects USB MIDI pad controllers on plug-in, parses multi-message chord packets & running status, supports one-click per-lane MAP learning, and includes a dedicated 16-beat hardware latency calibration routine.

PORTFOLIO & CODEBASE OVERVIEW

CLEAN MODULAR SWIFT ARCHITECTURE

Engineered with strict separation of concerns across real-time audio/MIDI, 120Hz SpriteKit rendering, SwiftUI reactive state, and SwiftData persistence. Click any module to view the source code on GitHub.

AudioManager.swift ↗ AVAudioEngine + RT DSP

Manages 5 drum kits × 4 voices × 3 velocity tiers × 3 transient trim modes, 6-voice polyphonic node pools per drum lane, hi-hat choke groups, studio reverb, and lookup-table Rhodes/Bass accompaniment synthesis.

MIDIManager.swift ↗ CoreMIDI + Hot-Plug

Safe multi-message MIDI packet parser supporting chords, running status, Note-On velocity=0 handling, automatic USB device hot-plug discovery, and zero-hop real-time audio callback dispatch.

GameScene.swift ↗ SpriteKit 120Hz Engine

Deterministic elapsed-time note scheduler in update(_:), scrolling bar/beat grid markers, phase-locked metronome & backing track triggers, and keyboard fallback (A,S,D,F / 1,2,3,4).

PatternBuilder.swift ↗ 18 Grooves + Swing Math

Defines MusicStyle, DrumKit, SampleLatencyMode, and PatternBuilder with authentic MPC 16th-note swing offsets and 3 progressive 32-step variations per genre.

DataManager.swift ↗ SwiftData + UnfairLock

Persists PracticeSessionRecord history and custom MIDI note mappings via SwiftData while maintaining an OSAllocatedUnfairLock snapshot for lock-free CoreMIDI thread lookups.

ContentView.swift ↗ SwiftUI HUD + Inspector

Hardware-inspired top transport bar, glowing MUSIC accompaniment toggle, style & variation pill browser, sample latency selector, and LeftContextPanel MIDI Learn & session analytics.

GET STARTED IN 30 SECONDS

INSTALLATION & HARDWARE SETUP

Download the standalone macOS disk image or build directly from source in Xcode.

01

Download & Mount .DMG

Grab FingerIN.dmg (2.8 MB), double-click to mount the disk image, and drag FingerIN.app into your Applications folder.

02

First Launch (Indie Build)

Because FingerIN is ad-hoc signed without an Apple notarization certificate, right-click FingerIN.app → Open on first launch, or clear quarantine in Terminal:

xattr -cr /Applications/FingerIN.app
03

Plug Pads or Use Keyboard

Connect any USB MIDI pad controller (click MAP in the left panel to assign custom pads) or play immediately with keys A, S, D, F / 1, 2, 3, 4 and Space.
